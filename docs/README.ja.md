# Neuro-CanvasLMS

[English](../README.md) · [简体中文](README.zh-CN.md) · [Español](README.es.md) · **日本語** · [हिन्दी](README.hi.md)

**あなたの Canvas LMS を、Claude と ChatGPT に直結。** コース、締め切り、成績、講義資料が、どのチャットでも、どのデバイスでも AI の知識になります。Canvas を使っているすべての学校で利用できます。

> 「今週の締め切りは？」·「MATH 132 の第 5 回講義を要約して」·「HW 3 にどんなフィードバックがあった？」·「第 12 回のコード ZIP には何が入ってる？」

## Neuro-CanvasLMS が選ばれる理由

| | |
|---|---|
| ☁️ **あなたの PC では何も動かない** | クラウド上の Cloudflare Workers で動作。開きっぱなしのアプリもローカルサーバーも不要です。 |
| 🔌 **どのデバイスも起動しておく必要なし** | ノート PC を閉じても、スマホをポケットにしまっても大丈夫。claude.ai、デスクトップ／モバイルアプリ、Claude Code、ChatGPT から 24 時間 Canvas にアクセスできます。 |
| 💸 **無料** | Cloudflare の無料プランで動き、学生一人には十分すぎる容量です。 |
| 🧠 **ファイルは会話の中に残る** | AI が読んだ講義ノートや PDF は、その会話とともに AI プロバイダーのサーバーに保存されます。ダウンロード不要です。 |

Canvas と AI をつなぐツールの多くは **ローカル** ツールです。自分の PC で動かしている間しか使えず、デスクトップやコーディング用アプリの中でしか使えません。Neuro-CanvasLMS はあなた自身の Cloudflare アカウントで動く **リモートコネクタ** なので、スマホや ChatGPT でも使えます。

## 主な機能

- **61 個の読み取り専用ツール：** コース、モジュール、ページ、ファイル、課題、提出物、成績とフィードバック、ルーブリック、お知らせ、ディスカッション、受信トレイ、カレンダー、To Do、グループ、小テスト履歴、プロフィール。
- **ファイルを本当に読める：** PDF・Word・PowerPoint・Excel からテキストを抽出。約 90 種類のコード／テキストファイルと Jupyter ノートブック（セルと出力）も読めます。ZIP はサーバー側で展開（一覧と、各コード／テキストファイルの中身）。スキャンや手書きの PDF はそれと判別し、元ファイルを渡して AI が 1 ページずつ画像として読みます。
- **リンク先のファイルも読める：** モジュールからリンクされた Google ドキュメント／スライド／スプレッドシート、Google ドライブ、Dropbox のファイルとフォルダ、GitHub のファイルとリポジトリも、公開共有（「リンクを知っている全員」）されていればテキストとして読めます。
- **コースが隠しているファイルも見つかる：** 多くのコースは学生にファイル一覧を見せません。コネクタはホームページ、シラバス、モジュール、課題、お知らせ、そこからリンクされたページを探すので、AI は「第 12 回のスライド」を名前で見つけられます。
- **設計から読み取り専用：** 固定の `GET` リクエストのみ。課題の提出、メッセージ送信、小テストの開始、Canvas 上の変更は一切行いません。
- **あなた専用：** あなた自身の Cloudflare アカウントにデプロイされ、あなたの Canvas アカウントに紐づきます。作者を含め、誰もあなたの Canvas トークンを見ることはありません。

## インストール（約 5 分）

必要なもの：[Node.js 22+](https://nodejs.org)、無料の [Cloudflare アカウント](https://dash.cloudflare.com/sign-up)、Canvas のログイン。ターミナルで次を実行します：

```bash
npx github:BloodyReginaa/Neuro-CanvasLMS
```

インストーラーが Cloudflare にサインインし（ブラウザでページが開くので **Authorize** をクリック）、学校の Canvas アドレスを尋ね、あなたのアカウントにコネクタをデプロイして動作確認します。その後：

1. **Canvas トークンを作成：** Canvas → アカウント → 設定 → **+ 新しいアクセストークン**。学校によって有効期限が制限されます（UMass Amherst では最長 30 日）。表示は一度きりなのですぐコピー。
2. **Claude：** 設定 → コネクタ → **カスタムコネクタを追加** → インストーラーが表示した URL を貼り付け（コピー済み）→ **接続** → Canvas トークンを貼り付けて認可。モバイルアプリや Claude Code を含め、Claude を使うどこでも使えます。
3. **ChatGPT：** 開発者モードで同じ URL のカスタムコネクタを追加。
4. 新しいチャットで「今週の課題は？」と聞いてみてください。

AI に任せたい場合は、このリポジトリをクローンして Claude Code（または Codex）で開き、「Canvas コネクタをセットアップして」と伝えてください。[`SKILL.md`](../.claude/skills/canvas-connector-setup/SKILL.md) に沿って進めます。

**Canvas トークンの期限が切れたら：** 新しいトークンを作り、AI アプリでコネクタを切断 → 再接続して貼り付けるだけ。再インストールは不要です。

## 更新・アンインストール

- **更新：** 同じ `npx` コマンドをもう一度実行。保存済みの設定を使うので質問はなく、現在のコードをデプロイし、ストレージと接続はそのまま残ります。再接続は不要です。新しいバージョンが出ると AI が知らせてくれます。
- **アンインストール：** `npx github:BloodyReginaa/Neuro-CanvasLMS uninstall` を実行し、Canvas トークンと AI アプリのコネクタを削除してください。

## 仕組み

```
Claude / ChatGPT ──OAuth──▶ あなたの Cloudflare 上の Neuro-CanvasLMS ──読み取り専用 API──▶ 学校の Canvas
 （どのデバイスでも）        （常時稼働。Canvas トークンを暗号化して保存）
```

## プライバシーとセキュリティ

- トークンはあなたの Worker と学校の Canvas にのみ送られ、あなた自身の Cloudflare KV の認可レコード内に暗号化して保存されます。
- コネクタは接続時にあなたの Canvas アカウントに紐づき、他のアカウントは拒否します。
- OAuth を完了できるのは Claude・ChatGPT・ローカルクライアントのみです。
- コース内容は信頼できないデータとして扱い、指示としては実行しません。
- ダウンロードは上限 15 MiB・HTTPS のみ・プライベートネットワーク遮断。
- Canvas の権限はそのまま適用され、もともと見られる内容しか読めません。
- コネクタは 1 日 1 回、このプロジェクトの GitHub から最新のバージョン番号を読み取り、AI が更新を知らせられるようにします。あなたに関する情報は何も送りません。
- AI が読んだファイルは、会話の一部として AI プロバイダーがそのプライバシー規約に従って保存します。チャットを削除すれば消えます。

利用前に、個人アクセストークンや外部ツールに関する学校の規定を確認してください。

## 制限

- 15 MiB を超えるファイルはコネクタ経由では読めません（Cloudflare Worker のメモリ制限）。ダウンロードしてローカルの Claude Code で開いてください。
- Gradescope・WebAssign・外部サイト・ロックされた内容・New Quizzes の内部データは対象外です。
- ファイル／小テストのページを非表示にしているコースもあります（403/404）。コース内のどこかでリンクされているファイルは見つかります（上記）。小テストは非表示のままです。
- UMass Amherst の Canvas（Instructure がホスト）で動作確認済み。他の学校でも動くはずですが、Canvas を自前でホストしている学校では、コネクタがまだ許可していないサーバーからファイルが配信される場合があります。
